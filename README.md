# Our Story (birthday website)

    npm install
    npm run dev      # local preview
    npm run build    # outputs ./dist

Deploy the `dist` folder to any static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages).
Text, the Chapter 9 code and optional photos are in the `CFG` object at the top of `src/App.jsx`.
To add real photos, put files in `public/` and set `photo: "/yourfile.jpg"` on a memory.
Decorative cat and library images load from Unsplash and need an internet connection.
